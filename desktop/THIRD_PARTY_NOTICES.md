# Third-party notices and source availability

Original FringeScope code, documentation and synthetic inputs are MIT licensed; third-party components retain their own terms. The application license does not relicense those components. `licenses/COMPONENTS.json` records versions and collected notice paths for the 30 distributions found in the verified packaging module graph. Full copied notices are under `licenses/`, including the Python distribution license, font notices and PyInstaller bootloader terms. No proprietary Palatino font file is distributed.

Principal runtime components include Python, NumPy/OpenBLAS, SciPy, Matplotlib, Pillow, packaging, PySide6 and shiboken6. Transitive components include contourpy, kiwisolver, fonttools, cycler, python-dateutil, pyparsing, six, setuptools and its included helpers. The inventory is based on collected modules; inclusion of a notice does not mean every optional upstream component is used. Python's license file also contains notices for its bundled components, including libffi and Microsoft Distributable Code restrictions. Windows runtime DLL redistribution is not covered by FringeScope's MIT grant.

The Qt community-license route is described by [Qt for Python licensing](https://doc.qt.io/qtforpython-6/licenses.html) and [LGPL text](https://doc.qt.io/qt-6/lgpl.html). Qt/PySide license texts, retained upstream third-party attributions and notices are under `licenses/Qt-upstream`. A commercial Qt license is not claimed. Qt Core, Gui, Widgets, Network, Test and SVG shared libraries are included by the current package, along with selected plugins/translations. Modules and individual third-party code retain the license choices and conditions in their source notices.

The locally prepared companion sources are unmodified Qt Base, Qt SVG, Qt Translations and pyside-setup 6.11.2 source archives. Their official URLs, SHA-256 values and successful comparison with upstream checksums are recorded in `licenses/QT_SOURCE_ARCHIVES.json`. They cover source modules; they do not prove an independently reproduced upstream wheel build or identical compiler configuration. See `licenses/QT_SOURCE_AND_REPLACEMENT.md` for preservation and replacement instructions.

**Browser edition.** The static site in `web/` redistributes one third-party file: the Plotly.js 4.3.0 cartesian bundle (MIT), with its license in `web/vendor/PLOTLY_LICENSE.txt`. At run time, the Explore page loads Pyodide 314.0.8 (MPL-2.0) with CPython, NumPy, SciPy and OpenBLAS (each under its own license) from jsDelivr at a pinned URL; the site does not redistribute those files. If they are later self-hosted, their notices must be added here.

Binary releases of 0.11.0 are published together with these notices and the four Qt/PySide 6.11.2 source archives. Before release, every bundled Qt, PySide6 and shiboken6 binary (36 files) was checked byte-for-byte against the official PySide6-Essentials and shiboken6 6.11.2 wheels, the same version as the source archives. The Qt libraries are ordinary shared DLLs in `_internal`; a trial copy with a substituted `Qt6Core.dll` started and passed the application self-test, so no integrity check prevents replacement. Qt was not rebuilt from source, and the upstream wheel build configuration was not reproduced. This is a technical record, not legal certification.
