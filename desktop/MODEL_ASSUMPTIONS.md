# Model assumptions and provenance

The runtime source is one analytic ΔA matrix inspired by photosystem I (PSI) difference spectra. The main workspace and demonstration chemical panels share its generator. Positive/negative amplitudes are retained. The reference S₀ is a distinct assumed single-beam envelope with a positive default minimum about 0.41 in arbitrary intensity units, not measured sample absorbance or detector response.

The source lifetimes are displayed as 12.16 and 449.14 µs; full values and coefficients are in synthetic_model.json and exports. β = 1. A causal residual is C = 0.08 R + 0.04 H. The fractions, Gaussian widths/amplitudes and persistence are sensitivity assumptions. Heating centers use the signed PSI features described by Nelson et al. (2026), §6.7/Figs. 7–9. The recombination parameterization has declared archival influence; no measured arrays are included. The current residual is not a determined third molecular state or calibrated thermal tail.

Time centers span −153–3381 µs with 6 µs spacing. Chemical bases are bin averaged; 100 µs spectra use labeled linear interpolation. Motion/electrical terms are evaluated at bin centers. Source functions have a linear 35 cm⁻¹ edge taper and are zero outside 1120–1950 cm⁻¹. No runtime smoothing, baseline correction or amplitude normalization is applied. Paired axis reversal is used internally only when required for interpolation; stored/displayed/exported wavenumbers remain descending.

The mathematical 513-channel band spans about 2106.39–1053.20 cm⁻¹. The 1024-point periodic, phase-zero interferogram is a model construction, not an OPUS raw acquisition. The dissertation's reported acquired endpoint near 1065.54 cm⁻¹ is distinct. The reference threshold is 1% maximum. Nonpositive reconstructed intensities remain masked; no positive floor is substituted.

The production displacement engine uses a fourth-order physical-wavenumber expansion. Its 0.25 rad warning is not a universal accuracy guarantee: the bounded audit found spectral discrepancies about 2.86 µOD at 0.25 rad and 87.32 µOD at 0.50 rad for one OPD-dependent pattern. Exact uniform-displacement lessons are separate from the OPD-dependent approximation and actual instrument phase correction. Magnitude and fixed-real readouts are sensitivity models.

Continuous optical leakage is included in reference and signal. It can dilute a real difference but cancels for a stationary unchanged sample. Visible responsivity, path/coherence, filter response and source power remain unmeasured. An optical-wavelength alias requires OPD-dependent coupling; uniform direct bypass does not have that carrier. Pulses use an assumed Gaussian/tail/electronics response integrated through bins. A pulse leading half can enter the −3 µs bin. Temporal response validation checks numerical consistency, not physical calibration.

The electrical example's spatial coupling is assumed. 14 × 60 = 840 Hz does not identify a source. Coaddition is performed before the logarithm; harmonic coherence depends on shot/step timing. No blanket 1/√N artifact suppression is assumed. Fixed demonstrations impose coherent OPD phase and state their references, AC detector normalization and graphical offsets.

Unweighted fits project signed amplitudes; free fits optimize log lifetimes with β fixed. No SEM/confidence interval is asserted. Numerical recovery and spectral similarity do not establish physical assignments. Full settings/grids/masks remain in exports. Dark/light appearance does not alter data. Original application code and synthetic inputs use the MIT license. Clean-second-host verification and complete binary corresponding-source/build-input verification are not established by numerical tests.
