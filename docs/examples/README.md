# Synthetic FringeScope examples

These are original analytic simulation examples for FringeScope 0.11.0. They are not measured PSI spectra, a digitized literature curve or calibrated instrument data. The PSI-inspired model's archival influence, literature-guided features and limitations are documented in `desktop/MODEL_ASSUMPTIONS.md`, `desktop/THEORY.md` and `desktop/synthetic_model.json`, relative to the repository root.

| File | Contents | Axes and units |
| --- | --- | --- |
| `synthetic_ideal_spectrum_100us.csv` | Ideal difference spectrum at 100 µs | `wavenumber_cm-1`, descending; signed `DeltaA_OD` |
| `synthetic_ideal_kinetics.csv` | Ideal kinetic trace at the nearest channel to 1697 cm⁻¹ | `time_us`, increasing; signed `DeltaA_OD` |
| `settings.json` | Generator parameters, seed, selections, processing and scientific input hashes | Time in µs; wavenumber in cm⁻¹; mirror amplitude in nm; absorbance in OD |

The ideal model includes two bin-averaged exponential components and a causal non-decaying residual; all components are zero before excitation. The residual is part of the specified chemical input, not an instrumental artifact. Artifact sources are disabled for these ideal examples.

Absorbance follows the logarithmic intensity-ratio convention; signed positive and negative difference bands are retained. No smoothing, baseline correction or amplitude normalization is applied. The selected 100 µs spectrum is linearly interpolated between native 99 and 105 µs bin centers. The kinetic trace uses the nearest native spectral channel, approximately 1697.04 cm⁻¹, without spectral interpolation. Full-precision selections and generation parameters belong in `settings.json`; display rounding must not change those inputs.

The complete time/wavenumber matrix is generated by the simulator. These two CSV files are selected slices and should not be described as a complete experimental dataset. Any additional reference cases should record native grid order, matrix axis order, masks, settings, fit constraints, seeds and exact source identifiers.

Reproduce these slices with `python -X utf8 tools/generate_examples.py --output NEW_DIRECTORY` from the repository root in the pinned runtime. The generator refuses an existing output directory. Compare the numeric CSV values and scientific input hashes with these files; generator environment metadata may differ across runtimes. Hashes identify the LF-normalized scientific files in this source distribution. The generator records dimensions, native grids and processing in `settings.json`.
