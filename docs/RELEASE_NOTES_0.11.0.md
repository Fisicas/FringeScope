# FringeScope 0.11.0 — prepared release notes

FringeScope makes step-scan FTIR artifacts visible in linked spectral and kinetic views. Start with the ideal synthetic PSI-inspired signal, then toggle mirror motion, continuous globar leakage or prompt 532 nm pickup. The guided tour and theory connect those changes to optical-path sampling, detector intensity, phase and time-bin integration.

This initial prepared release includes the Windows installer/standalone folder, source, synthetic model inputs, complete offline reading material and original synthetic demonstration figures. No experimental spectral matrices are supplied. MIT licensing was approved by the author. User-reported stage-5 usability testing was accepted on November 15, 2026.

Known limits: displacement expansion has a bounded validity domain; source power, detector response and actual mirror waveform are not calibrated; 840 Hz is illustrative; no experimental mechanism is identified. The installer is unsigned. Clean-second-host verification, final binary redistribution/source review and a live newer-release update remain explicitly tracked in the approval packet. Update checks remain disabled in the review build.

A responsive browser edition (FringeScope Web) is prepared in `web/` and validated locally, but it is not deployed; the prepared Windows binaries do not include it. Zenodo integration and DOI registration are not part of this preparation. Publication requires separate approval of the final asset manifest; this document is not a record of publication.
